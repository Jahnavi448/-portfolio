## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/Jahnavi448/-portfolio.git
```

Move into the project directory:

```bash
cd -portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown by Vite in your browser.
